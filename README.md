# Shot List
This is a program used to help keep track of your shots lists that you need to record for social media

For example, if you found a B-Roll clip you want to re-create from Instagram. 
You can go ahead and take a screenshot of it, then drag it into the webapp.

You can upload a lot of images at once or just 1 single inspiration shot.

Think of it like a to-do list but with images, and each image you finish recording you click as recorded.

This should help your B-Roll shots easier and faster.

Just a little something I did for myself which I found helped, so I hope it helps someone
